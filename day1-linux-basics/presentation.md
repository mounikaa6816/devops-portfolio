# Day 1: Linux Basics — 5-Minute Presentation

## 1. Introduction

Linux is an operating system widely used in servers, cloud computing, and DevOps environments.

## 2. Navigation Commands

* `pwd` — Displays the current directory.
* `ls` — Lists files and directories.
* `cd` — Changes directories.
* `uname -a` — Displays system and kernel information.

## 3. File and Directory Management

* `mkdir` — Creates directories.
* `touch` — Creates files.
* `cp` — Copies files.
* `mv` — Moves or renames files.
* `rm` — Removes files.

## 4. File Reading and Searching

* `cat` displays file contents.
* `nano` edits text files in the terminal.
* `find` searches for files and directories.

## 5. Disk Usage and Package Management

* `df -h` displays filesystem space.
* `du -sh` displays directory size.
* `apt search` searches available packages.
* `sudo apt update` refreshes package indexes when administrative access is available.

## 6. Connection to DevOps

Linux skills support server management, troubleshooting, shell scripting, cloud infrastructure, Docker, Kubernetes, and CI/CD pipelines.
