# Day 3 — Azure Storage and GitHub Repositories
## 5-Minute Presentation

### 1. Introduction
Today I practised Azure Blob Storage and Git local and remote repositories.

### 2. Azure Storage
Azure Storage provides cloud storage for application data, documents, images, and backups.

### 3. Storage Account, Container, and Blob
- Storage Account: The main Azure storage resource.
- Container: Organizes blobs.
- Blob: An individual object stored in Blob Storage.

### 4. Practical Demonstration
- Opened the existing Azure Storage Account.
- Created a private container named `lab-container`.
- Uploaded a sample text file.
- Inspected the blob properties, including blob type, size, content type, and encryption status.

### 5. Git Local Repository
A local Git repository stores project files and commit history on the computer.

Commands:
- `git status` — checks the working-tree state.
- `git add` — stages changes.
- `git commit` — saves staged changes locally.

### 6. Git Remote Repository
A remote repository is hosted on GitHub and supports collaboration and backup.

Commands:
- `git remote -v` — displays configured remotes.
- `git push` — uploads commits.
- `git pull` — fetches and integrates remote changes.

### 7. DevOps Relevance
Azure Blob Storage can store application data and backups. Git and GitHub help track changes and collaborate on code and configuration.

### Conclusion
This lab introduced cloud object storage and the basic Git workflow from local changes to a remote repository.
